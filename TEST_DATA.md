### 2. Create Custom Itinerary
1. Click "Plan My Trip" button
2. **Step 1**: Select destination (try Paris or Goa)
3. **Step 2**: Choose travel month and duration
4. **Step 3**: Select travel companion type

## API Endpoints for Testing

### Get Trending Destinations
```bash
GET http://localhost:5000/api/destinations/trending
```

### Create Itinerary
```bash
POST http://localhost:5000/api/itineraries
Content-Type: application/json

{
  "destination": {"city": "Paris", "country": "France"},
  "travelMonth": "May",
  "duration": 5,
  "travelCompanion": "couple",
  "travelMood": "culture",
  "budget": {"min": 2000, "max": 5000, "currency": "USD"},
  "departureCity": "New York"
}
```

### Get Available Hotels
```bash
GET http://localhost:5000/api/itineraries/hotels/available?city=Paris
```

### Get Available Activities
```bash
GET http://localhost:5000/api/itineraries/activities/available?city=Paris&mood=culture
```
